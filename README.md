# Everblush
Everblush is a very cool theme. For Aurora, it looks amazing! Feel free to install! 

# Installation
**You can install this theme by using Aurora's CLI :**

```
aurora download-theme https://github.com/TheAhumMaitra/Everblush-For-Aurora
```

## Mannual installation 
Clone this repo in `.config/themes`
